# Outisseus personal site

Static GitHub Pages personal site with separate public identities and privacy boundaries.

## Purpose

- `/` is the general personal profile: Builder / Financial Adviser / Life.
- `/builder/` is the X conversion and proof-of-work profile, including writing.
- `/builder/building.html` is the public build log.
- `/insurance/` is a single-screen adviser portal for Client Tools / Research / AI.
- `/insurance/tools/` is the stateless, approval-gated online toolkit.
- `/insurance/reports/` contains the public research gallery; `/insurance/ai/` reserves the expert-system interface.
- The published Chinese novel remains on its existing Notion Site and is presented within the Builder profile.

## Local preview

Serve this directory with any static file server and open the root page. No build step or external runtime dependency is required.

## Deployment target

The site deploys from the public `choeycui/choeycui.github.io` repository.
